</Note>

past.dev stores what your agent should remember, with the date each fact
happened. When a newer fact replaces an older one, answers lead with the new
value and mark the old one with the date it changed. It also controls which
users can read which facts, so one project can serve many customers.

This guide is for developers adding memory to an agent with past.dev's REST
API. Pick where to start:
