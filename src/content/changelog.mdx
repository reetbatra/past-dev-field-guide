## October 28, 2026 (second version)

- Restructured by content type, following GitHub's content model and
  Mintlify's content types: a 5-minute quickstart, a tutorial, a how-to guide,
  a concepts page and a known-issues page.
- The quickstart is one script in curl, TypeScript or Python. All three were
  run against a live project and print the same output.
- Added a copyable prompt for coding agents to the quickstart.
- Rewrote the build write-up as a step-by-step tutorial.

## October 28, 2026

- First version: introduction, quickstart, a guide to scoping memory per
  customer, and an API reference generated from past.dev's `openapi.json`
  (contract version 1.0.0).
- Every request and response on these pages comes from a real past.dev project.
