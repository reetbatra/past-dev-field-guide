This quickstart is for developers who want to see past.dev work before they
build with it. You'll send two notes about a customer whose plan changed, then
ask past.dev what plan they're on. It answers with the new plan first and marks
the old one as replaced.

You need:

- A past.dev account. [Sign up](https://sso.past.dev/sign-up) free, with no
  card. This quickstart uses about 3 of your 150,000 starting credits.
- A project API key from the [console](https://app.past.dev), under **API keys**.
- One of: `curl` with `jq`, Node.js 22.18 or later (it runs `.ts` files directly), or Python 3.9 or later. None
  of the scripts needs a package install.

<AgentPrompt heading="Using a coding agent?" title="Copy this prompt and it can add past.dev memory to your project.">
Add long-term memory to this project with the past.dev REST API.

- Base URL: https://api.past.dev/api/v1. Authenticate with the header `Authorization: Bearer $PAST_API_KEY`. Read the key from the environment and never write it into code.
- Send facts with `POST /ingest` (one) or `POST /ingest/batch` (`{"items": [...]}`, up to 1,000). Give each item a stable `id`, the text in `content`, and `timestamp` set to when the fact happened, in ISO 8601.
- Processing is asynchronous. Poll `GET /ingest/{ingestionId}` until `status` is `completed`. Stop with an error if it is `failed`.
- Ask with `POST /recall` and a body of `{"query": "...", "identity": "<the user's id>"}`. Pass `results` to the model in rank order. A result with `artifact.supersededAt` was replaced on that date. Cite `sources[].sourceId`.
- Every error response has a `code` field. Surface it instead of retrying blindly.

Official docs: https://past.dev/docs/memory-api/overview
</AgentPrompt>

## Set your API key

Export the key in the terminal you'll run the script from:

```bash
export PAST_API_KEY='past_sk_...'
```

## Run the script

Save the version for your language as `quickstart.sh`, `quickstart.ts` or
`quickstart.py`. It sends two notes in one batch, waits until past.dev has
read them, then asks the question.

<CodeGroup>
```bash curl
#!/usr/bin/env bash
set -euo pipefail
API=https://api.past.dev/api/v1
AUTH=(-H "Authorization: Bearer $PAST_API_KEY" -H "Content-Type: application/json")

# Fail with past.dev's own error code instead of a jq error.
check() { jq -e 'has("code") | not' >/dev/null <<<"$1" || { echo "past.dev error: $1" >&2; exit 1; }; }

# 1. Send two dated notes in one batch.
sent=$(curl -sS "$API/ingest/batch" "${AUTH[@]}" -d '{"items": [
  {"id": "northwind-kickoff", "label": "Call notes", "timestamp": "2026-01-14T10:00:00Z",
   "content": "Kickoff call with Northwind Traders. They signed up for the Starter plan with 5 seats. Main contact is Priya Shah, head of support."},
  {"id": "northwind-upgrade", "label": "Email", "timestamp": "2026-04-02T09:30:00Z",
   "content": "Email from Priya Shah at Northwind Traders: we have upgraded from the Starter plan to the Growth plan and now have 20 seats, effective today."}
]}')
check "$sent"
ingestion=$(jq -r .ingestionId <<<"$sent")
echo "Sent 2 notes"

# 2. Wait until past.dev has read them.
while true; do
  state=$(curl -sS "$API/ingest/$ingestion" "${AUTH[@]}")
  check "$state"
  case $(jq -r .status <<<"$state") in
    completed) echo "Processed"; break ;;
    failed) echo "Processing failed: $(jq -c .failure <<<"$state")" >&2; exit 1 ;;
    *) echo "Processing..."; sleep 10 ;;
  esac
done

# 3. Ask what's true now.
answer=$(curl -sS "$API/recall" "${AUTH[@]}" -d '{"query": "What plan is Northwind Traders on, and how many seats do they have?",
  "identity": "support-agent", "limit": 5}')
check "$answer"
jq -r '.results[] | "\(.rank). [\(.artifact.kind)] \(.content)" +
  (if .artifact.supersededAt then " (replaced \(.artifact.supersededAt[0:10]))" else "" end)' <<<"$answer"
```

```typescript TypeScript
const API = "https://api.past.dev/api/v1";
const headers = {
  Authorization: `Bearer ${process.env.PAST_API_KEY}`,
  "Content-Type": "application/json",
};

// Every past.dev error carries a `code`. Fail with it instead of a TypeError.
async function call(path: string, body?: unknown) {
  const res = await fetch(API + path, {
    method: body ? "POST" : "GET",
    headers,
    body: body ? JSON.stringify(body) : undefined,
  });
  const json = await res.json();
  if (!res.ok) throw new Error(`past.dev error: ${JSON.stringify(json)}`);
  return json;
}

// 1. Send two dated notes in one batch.
const sent = await call("/ingest/batch", {
  items: [
    {
      id: "northwind-kickoff", label: "Call notes", timestamp: "2026-01-14T10:00:00Z",
      content: "Kickoff call with Northwind Traders. They signed up for the Starter plan with 5 seats. Main contact is Priya Shah, head of support.",
    },
    {
      id: "northwind-upgrade", label: "Email", timestamp: "2026-04-02T09:30:00Z",
      content: "Email from Priya Shah at Northwind Traders: we have upgraded from the Starter plan to the Growth plan and now have 20 seats, effective today.",
    },
  ],
});
console.log("Sent 2 notes");

// 2. Wait until past.dev has read them.
while (true) {
  const state = await call(`/ingest/${sent.ingestionId}`);
  if (state.status === "completed") break;
  if (state.status === "failed") throw new Error(`Processing failed: ${JSON.stringify(state.failure)}`);
  console.log("Processing...");
  await new Promise((resolve) => setTimeout(resolve, 10_000));
}
console.log("Processed");

// 3. Ask what's true now.
const answer = await call("/recall", {
  query: "What plan is Northwind Traders on, and how many seats do they have?",
  identity: "support-agent",
  limit: 5,
});
for (const r of answer.results) {
  const replaced = r.artifact.supersededAt ? ` (replaced ${r.artifact.supersededAt.slice(0, 10)})` : "";
  console.log(`${r.rank}. [${r.artifact.kind}] ${r.content}${replaced}`);
}
```

```python Python
import json, os, time, urllib.error, urllib.request

API = "https://api.past.dev/api/v1"
HEADERS = {
    "Authorization": f"Bearer {os.environ['PAST_API_KEY']}",
    "Content-Type": "application/json",
}


def call(path, body=None):
    data = json.dumps(body).encode() if body is not None else None
    req = urllib.request.Request(API + path, data=data, headers=HEADERS)
    try:
        with urllib.request.urlopen(req) as res:
            return json.load(res)
    except urllib.error.HTTPError as err:
        # Every past.dev error carries a `code`. Show it instead of a stack of urllib frames.
        raise SystemExit(f"past.dev error: {err.read().decode()}")


# 1. Send two dated notes in one batch.
sent = call("/ingest/batch", {"items": [
    {"id": "northwind-kickoff", "label": "Call notes", "timestamp": "2026-01-14T10:00:00Z",
     "content": "Kickoff call with Northwind Traders. They signed up for the Starter plan with 5 seats. Main contact is Priya Shah, head of support."},
    {"id": "northwind-upgrade", "label": "Email", "timestamp": "2026-04-02T09:30:00Z",
     "content": "Email from Priya Shah at Northwind Traders: we have upgraded from the Starter plan to the Growth plan and now have 20 seats, effective today."},
]})
print("Sent 2 notes")

# 2. Wait until past.dev has read them.
while True:
    state = call(f"/ingest/{sent['ingestionId']}")
    if state["status"] == "completed":
        break
    if state["status"] == "failed":
        raise SystemExit(f"Processing failed: {state['failure']}")
    print("Processing...")
    time.sleep(10)
print("Processed")

# 3. Ask what's true now.
answer = call("/recall", {
    "query": "What plan is Northwind Traders on, and how many seats do they have?",
    "identity": "support-agent",
    "limit": 5,
})
for r in answer["results"]:
    replaced = r["artifact"].get("supersededAt")
    note = f" (replaced {replaced[:10]})" if replaced else ""
    print(f"{r['rank']}. [{r['artifact']['kind']}] {r['content']}{note}")
```

## Read the answer

Reading the notes took 20 to 60 seconds when I ran these scripts. Then you'll
see something like this:

```text
Sent 2 notes
Processing...
Processing...
Processed
1. [source] Email from Priya Shah at Northwind Traders: we have upgraded from the Starter plan to the Growth plan and now have 20 seats, effective today.
2. [temporal-anchor] Priya Shah: Northwind Traders upgraded to the Growth plan and changed to 20 seats (when): today. Resolved to 2026-04-02.
3. [source] Kickoff call with Northwind Traders. They signed up for the Starter plan with 5 seats. Main contact is Priya Shah, head of support.
4. [claim] Priya Shah: Northwind Traders seats: 20 seats (exactly). Effective from 2026-04-02.
5. [claim] Northwind Traders seats: 5 seats (exactly). Effective 2026-01-14 to 2026-04-02. (replaced 2026-04-02)
```

The April email ranks first. Line 5 is the January seat count, marked as
replaced on April 2. Line 2 shows past.dev turned "effective today" into a real
date, using the note's `timestamp`.

Your wording and order will differ a little. past.dev uses a model to pull the
facts out of each note, so each run phrases them its own way.

If the script prints `past.dev error:`, the `code` in the message says what
went wrong. The [troubleshooting table](/guides/scope-memory-per-customer#troubleshooting)
covers each code. Running the script again is safe and free: unchanged notes
come back as already processed.
