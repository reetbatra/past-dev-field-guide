## What it does

Most agent memory is a vector search over chunks of text. Ask "what plan is
this customer on?" and you get every chunk that mentions a plan, with no sign
of which one is current.

past.dev keeps the dates. You send each fact with the time it happened. When a
later fact replaces an earlier one, the answer leads with the new value and
marks the old one with the date it was replaced. You can also ask what was true
on any past date.

It also controls who sees what. Each reader asks as an **identity**, and each
fact can be limited to an **audience**. One project can hold memory for many
customers without one customer's facts showing up in another's answers.

## The four things to know

| Concept | What it is | Where you set it |
| --- | --- | --- |
| **Project** | The boundary. Nothing crosses between projects. Your API key picks the project, so request bodies never name it. | The console, when you create a key |
| **Data point** | One dated piece of text: a call note, an email, a ticket. Its `id` is yours, and resending the same `id` replaces it. | `POST /ingest` |
| **Identity** | The reader a recall answers as, such as a user or an agent. It can carry traits like `company: northwind`. | `identity` on `POST /recall` |
| **Audience** | Who may read a data point. Leave it out and every identity in the project can read it. | `audience` on `POST /ingest` |

## What a recall returns

You send a question and an identity. You get back ranked documents, each with
the date it happened. Some are your data points as you sent them. The rest are
**memories**, short statements past.dev extracted from them. `artifact.kind`
says which:

| `kind` | Example from the [quickstart](/quickstart) |
| --- | --- |
| `source` | Your original email, word for word |
| `claim` | `Northwind Traders plan: Growth plan. Effective from 2026-04-02.` |
| `observation` | `Northwind Traders signed up for the Starter plan (action).` |
| `temporal-anchor` | `upgraded to the Growth plan (when): today. Resolved to 2026-04-02.` |
| `mention` | `Raised an issue: SSO login failure on EU domain.` |

A memory that a later fact replaced carries `artifact.supersededAt`, the date it
stopped being true. Pass the results to your model in rank order and cite
`sources[].sourceId` when it answers.

## Costs and limits

- **Sending** costs 1 credit per 350 bytes of text, at least 1 per data point.
- **Recalling** costs 0.1 credit.
- **New accounts** get 150,000 free credits, or 400,000 with a work email. No card needed.
- **Processing isn't instant.** A data point is readable once its status is
  `completed`. In my runs that took between 1 and 8 minutes.

Building and testing everything in this guide, with every command run at least twice, used **under 10 credits**.
